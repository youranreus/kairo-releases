Kairo 0.2.5 本次更新

新增

  • 新增会话恢复、可配置的自动新对话与历史会话切换，纯文本历史可继续追问
  • 新增 /model 快捷指令，可在对话框中切换模型；唤起或切换时显示当前使用的模型

优化

  • 修复指令面板位置偏移，优化消息流式贴底与返回底部交互
  • 优化对话浮层自动收起机制：仅在明确点击外部应用时收起，支持向浮层拖拽文件而不关闭
  • 模型配置移入基础设置弹窗，优化多模型连接管理、协议选择与编辑布局
  • 优化模型密钥授权：配置连接时完成钥匙串访问验证，聊天时不再弹出授权窗口

修复

  • 消除消息列表未到最大高度时流式生成的窗口抖动与内部上下回弹

本更新包由 Apple Developer ID 签名并通过 Apple 公证，支持 arm64 与 x86_64 通用二进制。
