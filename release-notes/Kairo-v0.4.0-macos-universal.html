Kairo 0.4.0 本次更新

新增

  • 模型列表支持会话独立选择与恢复，⌘K 操作菜单可单独设置全局默认模型
  • 新增快捷指令“变换文本”动作，可按独立指令翻译、改写或整理源文本，并将结果传给复制或保存动作
  • 支持工作目录文件工具、MCP、Brave 搜索及会话分支、压缩和用量统计
  • 模型设置支持按 Provider 共享地址与授权，获取服务模型列表、选择 Pi 目录或手动添加多个模型
  • 手动与自动压缩在消息列表显示状态和成功分割线，普通会话切换、重启与创建分支后保留压缩记录
  • 对话支持 /compact 压缩上下文和 /fork 创建分支，分支结果使用统一提示，替代输入区会话菜单
  • 联网搜索支持六种来源、备用来源和已有模型凭据复用，新增网页正文读取和来源证据收集
  • 模型设置支持按模型保存思考强度，依据可用能力选择并用于后续对话请求

优化

  • 附件输入精简为文本和图片，移除 PDF 输入、旧会话迁移与独立缓存清理
  • 聊天、快捷指令、连接验证与自动标题统一使用内置 Pi 运行时
  • 供应商按账号或密钥登录，获取模型后统一选择启用，并可编辑思考、图片及 Token 容量
  • 账号授权改为自动浏览器登录，按状态精简操作，并恢复紧凑的供应商侧栏底栏
  • ChatGPT 登录默认浏览订阅模型，支持切换完整目录并按名称筛选同步
  • 订阅登录后展示明确的登录状态和可用账号信息，支持读取已有登录的账号摘要
  • 模型配置可直接验证未保存的参数，在参数卡片下方展示验证结果与错误信息
  • 完善云端模型列表获取与能力资料，支持稳定勾选、手动覆盖和恢复自动识别
  • 按供应商选择接入方式，配置可直接保存，并可单独选择模型测试调用
  • 模型服务支持快捷菜单、独立添加弹窗和供应商开关，同步模型自动刷新并以表格展示
  • 会话用量收拢至 /stats 只读命令面板，支持加载与不可用状态，临时会话统计仅在内存累计
  • 会话统计采用大数值卡片与累计用量占比条，清晰展示费用、上下文和四类 Token 构成
  • OpenAI搜索与来源验证的等待上限由30秒调整为60秒，保留取消和对话总时限约束
  • 统一对话工具与网络搜索的紧凑样式，优化正文排版、思考展开、状态动画及悬停操作，保留真实事件顺序与用量统计
  • 统一对话滚动视口，降低长回答持续输出时的卡顿，并保留原生工具与消息操作
  • 工具与搜索改为连续活动组，统一展开布局，保留来源访问、选区与滚动跟随。
  • 统一流式正文与思考展示，思考和工具内容支持独立吸底、上滚阅读及返回最新位置。
  • 将思考与工具过程区呈现为柔和圆角卡片，适配浅色、深色及辅助功能显示设置。
  • 将回复前的思考、工具与说明收纳为可展开过程，确认最终回复后收起，并优化缩进、层次线和稳定状态文案。
  • 过程进行中保持透明、结束后显示柔和卡片，移除摘要悬停底色与问题复制按钮，并对齐消息时间。
  • 移除回复底部重复的搜索来源列表，工具内来源和正文引用保持可查看，复制与导出内容保持不变。
  • 搜索服务未配置和回答失败时的状态提示更加柔和

修复

  • 选区超过长度上限或已有选区等待处理时，Kairo 面板会显示原因与重试方法，并保留原有草稿和选区
  • 从系统服务发送选区时，未知来源不再误标为 Kairo，关闭面板也不会跳回上一次应用
  • 修复 OpenAI 账号授权无法启动，并对齐供应商设置底部操作栏的分割线
  • 修复 OpenAI 授权后部分模型调用测试失败、无法正常对话的问题
  • 补齐英文菜单、设置入口和供应商模型同步界面的共享文案，减少中英文混杂
  • 修复未配置更新签名密钥的本地开发版本启动时弹出更新错误、阻挡设置打开的问题
  • 会话压缩仅在确认生成了新的上下文压缩记录后报告成功
  • 压缩上下文时显示执行进度和结果，无需压缩或失败时给出明确提示
  • 修复长对话达到上下文上限后无法自动压缩并继续回答的问题
  • 修复普通会话中会话操作和用量详情入口未显示的问题
  • 修复 Responses 接口认证失败时可能误触发上下文压缩的问题
  • 修复取消模型请求时过早结束清理、可能丢失登录令牌刷新结果的问题
  • 修复来源核验将网页处理异常当作成功结果的问题，避免异常详情进入证据内容
  • 网页拒绝访问或没有可读正文时保留搜索结果，并明确提示各网页的读取状态
  • 修复部分系统环境恢复重复会话记录时可能发生的崩溃
  • 修复流式回答多余空行、增高裁切和工具卡片反复刷新，保持选区与滚动稳定
  • 修复拖动回答底部导出图标时应用可能卡死的问题
  • 恢复返回底部与生成自动跟随，改善工具行焦点提示
  • 修复回答生成过程中底部状态行偶尔闪烁消失的问题
  • 修复回复分片密集时被误判失败而中断的问题，保留完整文字与正常取消清理。
  • 移除工具行焦点边框，避免展开搜索详情时布局跳动
