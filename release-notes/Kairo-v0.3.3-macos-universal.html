Kairo 0.3.3 本次更新

新增

  • 支持粘贴、拖放和选择 HEIC 与静态 WebP 图片，保留方向与透明度并移除位置等元数据
  • 会话默认保留三十天，支持按时间自动清理历史及附件，并可单独清理文件缓存
  • Responses 多轮对话使用本地上下文重放，缺少附件原件时提示开启新会话

优化

  • 助手设置支持表单偏好与补充指引，新增 Kairo 身份和能力边界指引，并改善编辑框与保存按钮
  • 输入附件支持玻璃标签，消息附件以图标和文件名展示，切换会话和重启后保留文件引用与内容
  • 模型连接改用 Responses 对话，保留旧配置与密钥，特殊服务地址可在设置中更新
  • 输入框支持文字与文件标签混排、删除撤销，并在首次换行后保持底部操作栏布局

修复

  • 阻止回答和历史中的不安全链接在应用内打开
  • 附件增删时输入框与消息容器顶部保持固定，消息区域高度直接更新，避免下沉回弹
  • 移除历史会话只读限制，文件缓存缺失或清理后仍可继续对话
  • 支持从 Finder 复制文件后直接粘贴为对话附件，保留文本粘贴与撤销操作
  • 修复对话面板在展开模型与历史菜单时无法增高的问题，调整尺寸期间输入框保持稳定
  • 通过菜单或快捷键打开设置时自动隐藏对话面板，再次打开设置也保持一致
  • 补充指引输入框获得焦点后隐藏占位提示，避免中文输入法组字时文字重叠
  • 设置窗口正确参与台前调度，打开时临时显示 Dock 图标，关闭后恢复菜单栏模式
  • 输入面板从单行展开为多行时保持底部固定，避免先下沉再上移
  • 输入面板展开时同步调整可见区域，避免多行输入顶部被截断

本更新包由 Apple Developer ID 签名并通过 Apple 公证，支持 arm64 与 x86_64 通用二进制。
